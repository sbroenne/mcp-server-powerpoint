# PowerPoint Automation Guides

These guides show complete workflows rather than listing individual operations.

- [Create and verify a presentation](create-and-verify.md)
- [Update an existing presentation safely](update-existing-deck.md)
- [Build an accessible presentation](build-accessible-deck.md)
- [Apply a template without replacing content](apply-template.md)

All examples use 1-based slide and shape indexes, matching PowerPoint itself. Open or create a
file once, reuse its session ID, export visual work for review, and close the session when done.
