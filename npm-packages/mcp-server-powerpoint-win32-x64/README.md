# PowerPointMcp Windows x64 Runtime

Let AI assistants create, edit, and export PowerPoint presentations with slides,
charts, tables, images, and notes. This package provides the Windows x64 server
used by `@sbroenne/mcp-server-powerpoint`. It requires Microsoft PowerPoint 2016
or later and an interactive Windows desktop.

Install or run `@sbroenne/mcp-server-powerpoint` instead of installing this package
directly. x64 Node.js selects this runtime, including through
x64 emulation on Windows ARM64. ARM64 Node.js uses the separate native ARM64
runtime.
