# PowerPointMcp CLI Windows ARM64 runtime

Create and edit PowerPoint presentations from commands and scripts. This package
provides the native Windows ARM64 `pptcli.exe` used by `@sbroenne/pptcli` to work
with slides, text, charts, tables, images, and notes. It requires Microsoft
PowerPoint 2016 or later and an interactive Windows desktop.

Install or run `@sbroenne/pptcli` instead of installing this package directly.
ARM64 Node.js selects this package automatically.
