## Intent

Create a fast product introduction that shows PowerPoint MCP automating the real
PowerPoint desktop application. The story should make both entry points clear:
conversational MCP for interactive work and `pptcli` for command-line
automation. The overall feel should be polished, direct, and reliable rather
than flashy.

## Assets

- `gh-pages/docs/assets/images/icon.png` - existing PowerPoint MCP project icon.
- Repository site styles and product copy - source for the visual identity and
  accurate product claims.
- Live desktop capture - real PowerPoint automation footage created for the
  video.
