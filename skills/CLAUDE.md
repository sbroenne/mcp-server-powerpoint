# PowerPoint Agent Skills

The repository publishes three small Agent Skills: `powerpoint-mcp`,
`powerpoint-cli`, and optional `powerpoint-deck-design`. Their `SKILL.md` files
are the canonical skill content.

Detailed operational guidance is maintained under `gh-pages/docs/reference/`
and published at https://powerpointmcpserver.dev/reference/. Keep the installed
skills focused; do not copy the full documentation corpus or generated CLI help
into skill packages. MCP users should discover available arguments from the
live tool schemas, and CLI users should use `pptcli --help`.

For repository architecture, testing, and release rules, follow
`.github/copilot-instructions.md` and its linked task-specific instructions.
